# Accessibility Statement

_Last updated: 2026-09-18_

JellyWave aims to meet WCAG 2.1 AA where it reasonably can for a native desktop/mobile app: real alt text on cover art, labeled icon-only controls, keyboard-operable menus and dialogs (including closing any overlay with Escape), and color combinations checked against the 4.5:1 contrast minimum for normal text. This is an ongoing, best-effort goal from a one-person project rather than a certified compliance claim.

If you hit an accessibility barrier, please report it via [GitHub Issues](https://github.com/greenythebeany/jellywave/issues) — real reports are the fastest way to get something fixed.
